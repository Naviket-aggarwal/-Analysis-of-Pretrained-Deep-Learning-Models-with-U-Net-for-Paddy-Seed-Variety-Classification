# 🌾 Paddy Seed Variety Classification

## 📌 Project Title
Comparative Analysis of Pretrained Deep Learning Models with U-Net for Paddy Seed Variety Classification

## 🧠 Description
This project focuses on classifying paddy seed varieties using deep learning models like EfficientNet and U-Net.

All training, evaluation, and results (ROC curve, confusion matrix, accuracy plots) are included inside the notebook.

## 🛠 Tech Stack
- Python
- TensorFlow / Keras
- NumPy, Matplotlib

## ▶️ How to Run
Open the notebook `EfficientNet.ipynb` in Jupyter or VS Code and run cells.

## ⚠️ Note
Model training was performed on a GPU-enabled system.
